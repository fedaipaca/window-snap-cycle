# Window Snap Cycle

A KDE KWin script that snaps the active window to the left, right, center, or fills the screen. Press the same shortcut again to cycle through the available sizes.

## Shortcuts

| Action | Default shortcut | Sizes |
| --- | --- | --- |
| Left | `Ctrl+Alt+Left` | 1/2, 2/3, 1/3 of the work area |
| Right | `Ctrl+Alt+Right` | 1/2, 2/3, 1/3 of the work area |
| Center | `Ctrl+Alt+C` | 1/2, 2/3, 1/3 of the work area |
| Fill | `Ctrl+Alt+Return` | 100%, 90% of the work area |

The shortcuts can be changed in KDE's keyboard shortcut settings.
